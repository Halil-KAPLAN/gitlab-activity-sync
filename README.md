# GitLab Activity Sync

This repository mirrors my commit activity from a self-hosted GitLab instance (code.drupart.com.tr) to my GitHub contribution graph.

- Each commit here is empty and stands for one real commit I made on GitLab: it carries that commit's date, and its message is the original GitLab commit SHA.
- No source code is copied here; the code itself stays on GitLab.
- Only commits are mirrored. Merge requests, issues and reviews are not.
- Commits are imported daily by [gitlab-activity-importer](https://github.com/Halil-KAPLAN/gitlab-activity-importer).
